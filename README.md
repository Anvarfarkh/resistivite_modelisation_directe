# :earth_americas: Resistivity forward modelling Schlumberger

A simple Streamlit app showing the Resistivity forward modelling with Schlumberger array.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)]([https://resistivitemodelisation.streamlit.app])

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
